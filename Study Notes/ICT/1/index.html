What is Python?

Python is a high-level, interpreted programming language created by Guido van Rossum and first released in 1991. It emphasizes code readability and simplicity, making it one of the best languages for beginners.

Python Philosophy
"Simple is better than complex." — The Zen of Python

Key Features

  • Readable: Clean syntax that reads like English
  • Interpreted: Run code line by line, no compilation needed
  • Dynamically typed: No need to declare variable types
  • Cross-platform: Works on Windows, macOS, Linux

Your First Program

The classic first program in any language prints "Hello, World!" to the screen. In Python, this is just one line:

print("Hello, World!")

The print() function outputs text to the console. Anything inside the parentheses and quotes is printed as-is.

Variables & Data Types

Variables store data in memory. Python is dynamically typed, so you don't need to specify the type:

name = "Alice"      # String (text)
age = 17            # Integer (whole number)
height = 1.65       # Float (decimal)
is_student = True   # Boolean (True/False)
Dynamic Typing
Variables change type freely: x = 5 then x = "hello" — both valid in Python.

Taking User Input

Use input() to get data from the user. It always returns a string, so convert to numbers when needed:

name = input("Enter your name: ")
age = int(input("Enter your age: "))
print("Hello", name, "you are", age, "years old.")
