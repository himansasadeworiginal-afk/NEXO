## NEXO ICT — Interactive Terminal / Code Playground Component

You are building a self-contained, reusable interactive terminal + code practice component for the ICT section of the NEXO study platform. This component will be embedded directly inside ICT programming lesson pages (each an index.html file in the Study Notes/ICT/ folder). It must match NEXO's existing dark green aesthetic exactly.

---

### WHAT TO BUILD

A single reusable HTML component file: `nexo-terminal.html`

This file contains a fully working in-browser code practice terminal that can be dropped into any NEXO ICT lesson page via an iframe tag:

  <iframe src="../../components/nexo-terminal.html?lesson=py-hello-world" width="100%" height="600px" style="border:none;border-radius:4px;"></iframe>

OR alternatively, output it as a self-contained embeddable JS component with a clear "copy this block into your lesson page" instruction.

The component must work with NO server, NO internet connection, NO external APIs — purely client-side, file:// compatible.

---

### PYTHON EXECUTION ENGINE

Since there is no server, Python code must run in the browser. Use Skulpt — a pure-JS Python implementation that runs client-side.

Load Skulpt from CDN:
  <script src="https://skulpt.org/js/skulpt.min.js"></script>
  <script src="https://skulpt.org/js/skulpt-stdlib.js"></script>

Skulpt integration:
- Configure Sk.configure({ output: outputFn, read: builtinRead })
- outputFn(text) appends text to the console output panel
- Handle errors: catch Sk.misceval.asyncToPromise rejections and display in rose/red color
- Support: print(), input() prompts (for input(), show a small inline prompt in the console — a text input appears at the bottom of the console area, user types their value and presses Enter, execution resumes)
- Timeout: if code runs for more than 5 seconds, terminate and show "Execution timed out" error
- After execution, show "— Program finished (Xs elapsed) —" in --text-dim

For input() handling specifically:
- When Skulpt calls input(), pause execution and show an input field in the console
- Style: background transparent, border-bottom 1px solid --green, color --green-light, monospace font
- Prefix with a green "? " prompt symbol
- On Enter: resume execution with the provided value
- On Escape: cancel with empty string

### PSEUDOCODE MODE

When language is set to Pseudocode:
- Do NOT execute anything (pseudocode is not runnable)
- The [▶ Run] button changes to [▶ Trace] 
- Clicking Trace runs a step-by-step visual trace:
  * Highlight each line of the pseudocode one at a time
  * Show a "Variables" side panel that tracks declared variables and their values
  * The trace simulates simple assignments (x ← 5), OUTPUT statements, and basic loops
  * Each step: 600ms delay, highlight current line in --green with 0.15 opacity background
  * A [Step] button and a [Play/Pause] button control the trace
  * A trace speed slider (Fast / Normal / Slow)
- Variable tracking panel:
  * Shows variable name (--teal) and current value (--amber) in a small table
  * Updates live as trace progresses
  * Background: --surface, border: 1px solid --border

The pseudocode interpreter for tracing only needs to handle:
  DECLARE varName : DataType
  varName ← value  (or = value)
  OUTPUT "text" or OUTPUT varName
  INPUT varName
  IF condition THEN / ELSE / ENDIF  (highlight but don't evaluate condition, just step through)
  FOR i ← 1 TO n / NEXT i  (actually loop n times in trace)
  WHILE condition DO / ENDWHILE  (step through, max 20 iterations to prevent infinite)

### CONFIGURATION SYSTEM

The terminal is configured by a global config object defined BEFORE the component script, so each lesson page can customize it:

  const NEXO_TERMINAL_CONFIG = {
    lang: "python",           // "python" | "pseudocode" | "javascript"
    lesson: {
      title: "Variables & Data Types",
      challenge: "Write a Python program that asks the user for their name and age, then prints: 'Hello [name], you are [age] years old.'",
      expectedOutput: "Hello Alice, you are 17 years old.",
      hint: "Use input() to get values from the user. Remember: input() always returns a string, so you don't need to convert age for printing with f-strings.",
      starterCode: {
        python: "# Write your solution here\nname = input('Enter your name: ')\n# Your code below\n",
        pseudocode: "BEGIN\n  DECLARE name : STRING\n  OUTPUT \"Enter your name: \"\n  INPUT name\n  // Complete the program\nEND",
        javascript: "// Write your solution here\nconst name = prompt('Enter your name:');\n// Your code below\n"
      }
    },
    theme: "nexo",            // always "nexo" for now
    showLineNumbers: true,
    autoRunOnLoad: false,
    fontSize: 14,             // px, user can adjust with Ctrl+/Ctrl-
    maxOutputLines: 200
  };

If no config is present, load a default "Hello World" challenge.

  Small copy icon button in the top-right of the editor area

### QUALITY REQUIREMENTS

- Must work by opening index.html directly (file:// protocol)
- Skulpt is the only CDN dependency (skulpt.org) — acceptable since it's a runtime, not a UI library
- All NEXO theme colors hardcoded as CSS variables at the top of the style block
- Mobile responsive: on screens < 768px, stack toolbar buttons into two rows, reduce editor min-height to 150px, font-size to 12px
- Accessible: all buttons have aria-labels, editor textarea has aria-label="Code editor", output panel has role="log" aria-live="polite"
- No memory leaks: clean up Skulpt execution on reset/new run
- The component must not interfere with the parent page's JS or CSS when embedded (use a unique prefix "nxt-" on all IDs and CSS classes inside the component)
- Comment every major section of the code clearly: // === EDITOR === // === EXECUTION ENGINE === // === PSEUDOCODE TRACER === // === CONFIG === // === UI EVENTS ===
