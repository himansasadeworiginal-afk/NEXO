#### Hide on scroll down / show on scroll up behavior

Track the user's scroll direction using a scroll event listener.

Variables needed:
- lastScrollY: stores the previous scroll position
- ticking: prevents scroll handler from firing too many times (use requestAnimationFrame)

Logic:
- If scrolling DOWN and scrollY > 80px: add class navbar-hidden to the navbar
- If scrolling UP: remove class navbar-hidden from the navbar
- If scrollY < 80px: always show the navbar (near the top of the page)

CSS for hiding:
  .navbar-hidden {
    transform: translateY(-100%);
    transition: transform 300ms cubic-bezier(0.4, 0, 0.2, 1);
  }
Default (shown) state also has the same transition so it slides back in smoothly.

When the global search overlay is open, always show the navbar regardless of scroll direction. Remove navbar-hidden class when overlay opens.
